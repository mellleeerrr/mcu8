# H.323 golden vectors

These files are test inputs, not recordings of a live call in this checkout.
`SHA256SUMS` pins every byte; `regenerate.py` rewrites all files from the
constants below plus the pinned pycrate runtime.

## Provenance

| Files | Origin |
| --- | --- |
| `polycom_alerting.tpkt`, `polycom_connect.tpkt`, `polycom_release_adaptive_busy.tpkt` | Byte-for-byte copies of the independent Polycom wire captures in `python/test_h323_sidecar.py` (2026-10-22), wrapped in a TPKT header so the native framing test can parse them. |
| `h245_incoming_olc.bin`, `h245_outgoing_ack.bin`, `h245_incoming_video_olc.bin`, `h245_outgoing_video_ack.bin` | The same captures' H.245 frames, copied from that test module. |
| `h225_setup_cleartext.tpkt`, `h225_setup_h235_token.tpkt`, `h225_setup_tls_only.tpkt`, `h225_connect_tls.tpkt`, `h225_release_security_denied.tpkt`, `h245_open_encryption_sync.bin` | Deterministic aligned-PER encodings generated by `regenerate.py` with pycrate 0.8.1 and the ASN.1 modules in `python/schemas`. They exercise the T16 fail-closed H.235/H.245-security policy. |

The Polycom files must not be edited to make a test pass. Replace them only
with a newer independent capture and say so in the commit message.

## What the harness proves

* Native TPKT/Q.931 framing accepts exactly one complete frame, extracts the
  two-octet H.225 User-User IE, and never invents media addresses from opaque
  ASN.1 bytes (`tests/golden_h323.rs`).
* Truncation and single-byte mutation of every vector returns an error instead
  of panicking; malformed/duplicated User-User IEs are rejected.
* The Python sidecar decodes every H.225 frame and rejects TLS-only
  `h245SecurityCapability`, H.235 `tokens` and H.245 `encryptionSync`
  (`python/test_golden_vectors.py`).
* H.245 OLC requests and their ACKs decode to the captured addresses/payloads;
  OLC requests re-encode byte-for-byte. `openLogicalChannelAck` is asserted by
  decoded value only: pycrate 0.8.1 emits a canonical length octet that differs
  from the two captured ACK bytes (0x06 vs 0x08); the remaining bytes match.

## Deliberately absent features

FastStart, reverse OLC and H.239 are **not implemented** by the current
Python sidecar. The audit (`docs/audit/2026-10-29/02_h323_p6.md` §7/§12)
stages them for the native stack; there are no fake golden vectors claiming
they work. H.235/SRTP is fail-closed: the gateway rejects encrypted calls with
`securityDenied` rather than silently downgrading them.

## Regenerate

```sh
~/.local/share/vks-mcu/h323-venv/bin/python3 regenerate.py
sha256sum *.tpkt *.bin > SHA256SUMS
```

The venv must contain pycrate 0.8.1. Regeneration is only needed when the
pinned ASN.1 schema or a capture changes; ordinary test runs read the files.
