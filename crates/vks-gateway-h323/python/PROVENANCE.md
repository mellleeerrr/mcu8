# H.323 codec provenance

`h323_sidecar.py`, `install_runtime.py` and the regression tests are authored for
this MIT/Apache-2.0 project. They implement bounded transport, call state and IPC.
They do not copy the H323Plus C++ implementation.

`h323_asn.py` is generated by Pycrate **0.8.1** from the three unmodified ASN.1
input files in `schemas/`:

- H.225.0 version 8, Packetizer 24 September 2022:
  https://raw.githubusercontent.com/willamowius/h323plus/master/src/asn/h225.asn
- H.245 version 17, Packetizer 24/27 September 2022:
  https://raw.githubusercontent.com/willamowius/h323plus/master/src/asn/h245.asn
- H.235 security messages (needed for imported ASN.1 types):
  https://raw.githubusercontent.com/willamowius/h323plus/master/src/asn/h235.asn

Input-file attribution/header comments are retained. The snapshot was obtained
on 20 October 2026. Schema hashes are recorded in `schemas/SHA256SUMS`.
`generate_codec.py` regenerates the Python ASN.1 object descriptions. They use
Pycrate's runtime; no Pycrate library code is vendored into this source tree.

Pycrate is a separate runtime dependency, pinned to the official pure-Python
wheel by SHA256 in `requirements.lock`. Its upstream distribution declares
**LGPL-2.1-or-later**, and contains its original license and copyright metadata:

- https://github.com/pycrate-org/pycrate
- https://github.com/pycrate-org/pycrate/blob/master/license.txt
- https://pypi.org/project/pycrate/0.8.1/

The sidecar is a separate Python process and can be replaced or modified through
`VKS_H323_PYTHON` / `VKS_H323_HELPER`. Distribution of that separate runtime must
retain upstream LGPL notices and satisfy the upstream license conditions.

Protocol implementation references (not copied source): H323Plus `src/h323.cxx`
uses a 384 kbit/s unrestricted digital Q.931 bearer for video, and
`include/codec/opalplugin.h` identifies H.264 GenericCapability and the H.241
non-interleaved RTP packetization OIDs. `plugins/video/H.264/h264-x264.h` maps
baseline profile to generic parameter 41 value 64 and H.264 level 3.1 to generic
parameter 42 value 71.

The regression packets are from explicitly requested diagnostic calls to the
user's Polycom RealPresence Desktop 3.5.0.59582 on 192.168.1.132, 20 October 2026
(Moscow time). They are independent peer-produced PER vectors, including CONNECT,
H.245 OLC and OLC ACK. Test transports do not place calls to that endpoint.
