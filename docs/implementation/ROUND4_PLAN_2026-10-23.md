## 2. Целевая модель геометрии (единая формула)

Холст — строго 16:9: `W = 1280`, `H = 720` (для любого запрошенного размера масштабируется
пропорционально). Базовая сетка раскладки задаётся `cols × rows` (дробные `col/colSpan`
допускаются только там, где это требует топология, — custom_22, codian_46).

Пикселизация на канвасе — **без зазоров** (иначе в композите будут тёмные швы):
```
cellW = W / cols        cellH = H / rows
x = round(col * cellW)  y = round(row * cellH)
width = round(colSpan * cellW)   height = round(rowSpan * cellH)
```
Последняя колонка/ряд замыкаются на `W`/`H` (`x1 = W`, `y1 = H`) — без накопления ошибки.

Зазор `G` — только для SVG-иконок селектора (визуальное разделение, у вендора ~0.9 px
в боксе 44×28). Иконки строятся из тех же слотов: каждая ячейка сжимается **равномерно
со всех сторон** на `h = G/2` (G — доля канваса, `G = round(maxX*0.02)`), поэтому все
одиночные ячейки одинаковы независимо от края, а внешний контур имеет поле `h`.

Топологии с заданными в ТЗ раскладками:
- `codian_custom_22`: 6 колонок × 5 рядов; окна 1 и 2 — `colSpan 2.5`, `rowSpan 2`;
  окно 3 — `col=5,row=0`; окно 4 — `col=5,row=1`; окна 5–22 — 3 ряда × 6 колонок.
- `codian_custom_14`: 6 колонок × 4 ряда; окна 1–2 — `colSpan 3`, `rowSpan 2`;
  окна 3–14 — 2 ряда × 6 колонок.
- `codian_43`: 4×5 равномерно; `codian_49`: 4×5 — верх 2 окна `colSpan 2, rowSpan 2`,
  низ 3 ряда × 4; `codian_50`: 6×6 — верх `colSpan 6, rowSpan 5`, низ 1 ряд × 6.
- `codian_46`: 4×4 — верхний ряд 4; средний ярус: левое крупное `col 0, span 1.5, rowSpan 2`,
  два центральных малых в `col 1.5` (rows 1 и 2), правое крупное `col 2.5, span 1.5, rowSpan 2`;
  нижний ряд 4. Симметрия относительно центра.
- PIP-раскладки: наложенные окна строго 16:9 — `codian_33`/`codian_39` 256×144,
  `codian_38` 320×180, `codian_51` 384×216, `codian_52` 224×126 (с сохранением позиций/углов).

## 3. Конструктор «Схема расположения участников»

Цель: в редакторе раскладок (ручной режим) появляется конструктор в вендорском стиле:
выбор числа участников/режима (равномерная сетка / spotlight с PIN / pin + лента),
живой предпросмотр на холсте 16:9 по алгоритму area-optimized gallery из
`meeting-grid-layout-core`, сохранение и применение через штатную цепочку.

Контракт (минимальная правка бэкенда): `payload.slots` с явными x/y/w/h уже перекрывает
базовую геометрию; конструктор формирует `payload = {mode:"manual", preset:"", type:"custom",
size:N, slots:[{position, x,y,width,height,role}]}`. Проверяется тестом
`explicit_geometry_from_constructor_reaches_engine` (LayoutDescriptor.geometry).

Реализация проектного слоя (без сборки npm, CSP `script-src 'self'`): портируется
framework-agnostic ядро (алгоритм поиска рядов + позиционирование, ~150-200 строк),
обёрнутое в секцию конструктора с вендорскими классами; никаких новых CSS/инлайна.
