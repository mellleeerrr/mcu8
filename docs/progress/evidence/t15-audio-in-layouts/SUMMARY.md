# T15 — вкладка «Аудиоканал(ы)» переехала внутрь вкладки «Раскладки»

Дата: 2026-10-22. Стенд: `http://127.0.0.1:8080` (admin/admin_password),
конференция `49b599d7-b5cd-45a7-8999-47a28c453a92`, страница сессии —
тот же UUID. Правка вендорного чанка применена к рабочему рантайму;
проверки — только Playwright, записей в БД нет.

## 1. Задача и решение

Заказчик: «перемести вкладку аудиоканалы во вкладку раскладки».

Первое, что показала проверка: вкладка «Аудиоканал» **уже** стоит сразу после
«Раскладок» — и на странице конференции, и на странице сессии. Значит
перестановка верхнего ряда — no-op, и единственное непустое прочтение задачи —
перенос содержимого аудиоканалов внутрь вкладки «Раскладки».

Четыре трактовки разбирались раздельно (вероятности по итогам раунда
контраргументации): (C) вложенная под-вкладка, (D) одновременное присутствие
двух списков в одной панели, (B) перестановка верхних вкладок, (E/F) спрятать
вкладку в другое место. Реализовано **(D)-вариант «слияние»**: вкладка исчезает
из верхнего ряда, блок аудиоканалов живёт внутри панели «Раскладки» вторым
блоком. Обоснование: (B) — no-op; (E/F) противоречат названной цели;
(C) потребовала бы второго таб-бара (в вендоре вложенных табов нет нигде) и
нового состояния, при этом «вкладка» растворялась бы в теле родителя —
в отличие от явного «переместить вкладку во вкладку».

## 2. Почему это не CSS-задача

- Панель вкладок одна, монтируется только активная (`currentComponent` в
  `index6.bundle`): на вкладке «Аудиоканал» блока раскладок в DOM **нет**.
- Vue при размонтировании компонента удаляет его корневой узел из текущего
  родителя (`remove: e => e.parentNode.removeChild(e)`): перенесённый вручную
  узел аудиоканалов **удаляется** при уходе с вкладки (`document.contains(...) === false`).
- Скрытие кнопки вкладки через CSS отвергнуто замерами: MDC строит свой список
  по селектору `.mdc-tab` (8 элементов при 7 видимых) ⇒ клавиатурная ловушка
  (4×`ArrowRight` не двигают фокус) и «нет активной вкладки»
  (`visible_active_tabs = 0`), при этом `pageerror` = 0.

Вывод: правка вендорного чанка — единственный рабочий путь.

### Правила патча

1. `tabList`: пункт «Аудиоканал(ы)» получает `hidden:!0` — `TcTabs` фильтрует
   `tabs.filter(e => !e.hidden)`, кнопка не рендерится вообще.
2. `modelValue` таб-бара: `conferenceCurrentTab === "Audio" ? "Layouts" : …`
   (и то же для сессии) — активная вкладка всегда совпадает с видимой панелью.
3. Рендер `LayoutTab`: панель аудиоканалов вторым ребёнком
   `main-card-body__container` (`(s(),b(wp,{key:3}))` / `(s(),b(PS,{key:3}))`).
4. `currentComponent`: `Audio:wp` → `Audio:iy`, `Audio:PS` → `Audio:PT` —
   страховка от «пустой карточки» без единой ошибки в консоли.
5. Шесть присваиваний `CurrentTab="Audio"` (возврат из редактора аудиоканала:
   «Назад», «Отмена», «Создать» — 3 в конференции, 3 в сессии) → `"Layouts"`.

### Вёрстка

Вендор: `.main-card-body { flex: 1 1 1px }` ⇒ два блока делят панель 50/50, и
пустой блок аудиоканалов занимает пол-экрана. Первая правка (оба блока по
контенту + прокручиваемый контейнер) прошла замеры на 1600×1000, но
**независимый аудит на низких вьюпортах нашёл дефект**: суммарный контент
пустого состояния 807 px > высоты карточки (783.7 на 1600×1000 и тем более
меньше на 1280×800 / 1024×768 / 1280×600) ⇒ flexbox сминает заголовок карточки
(74.2 → 56) и блок аудиоканалов выдавливается за нижнюю границу карточки
(`overflow: hidden`) — кнопка «Добавить» недостижима. На высоком вьюпорте дефект
не проявляется, поэтому проверять надо было по матрице разрешений, а не по
одному экрану.

Финальная политика (5 правил в `<style id="prostor-pnm-overrides">`):

- блок аудио — `flex: 0 0 auto; min-height: 0; max-height: 320px; overflow-y: auto`
  (своя высота, потолок, свой скролл при большом числе каналов);
- список раскладок — возврат к вендорскому `flex: 1 1 1px` (правило
  `:has(...) > .main-card-body:first-child`, 0,5,0) ⇒ растёт на остаток и
  сжимается, когда места мало;
- иллюстрация пустого состояния аудио **скрыта** (`display:none`) + компактные
  отступы. Не уменьшена, а скрыта: с иллюстрацией 120 px пустое состояние аудио
  = 270 px, и на 1280×800 / 1024×768 список раскладок не помещался в остаток
  (403 px против 312 / 280) — появлялась его собственная прокрутка, а кнопка
  «Добавить» списка раскладок уходила за нижний край блока. Без иллюстрации
  аудио = 138 px, сумма = 541 px — влезает даже в карточку 549.8 px;
  панель раскладок сохраняет вендорские 240×240 (ужимается «гость»);
- тело таблицы аудиоканалов `min-height: 140px` (вендорский
  `.tc-list{flex:1 1 80px}` показывал 2 строки из 12+);
- контейнер панели `overflow-y: auto` — страховка.
