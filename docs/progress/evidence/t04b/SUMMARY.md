## Покрытие (UI-клики, не API)
- **11 диапазонов** ряда выбора: `1, 2, 3, 4, 5+, 8, 9, 10+, 25, 34+` и
  icon-only **`overlap`** (в бандле 2.2.1.66 это отдельный rangeMap-ключ,
  gettext("overlap") пуст, поэтому кнопка без текста).
- Для каждого диапазона читается фактическое число ячеек (`initial.length`),
  затем участник ставится в **1, ceil(N/2), N** — то есть первая, средняя и
  последняя ячейки именно этой схемы, а не нижней границы диапазона.
  Для «+»-диапазонов проверено фактическое расширение: 5+ → 6, 10+ → 16,
  34+ → 36; для остальных число ячеек ровно N.
- В каждой целевой ячейке: bbox >20×20 px и имя SIP-участника; после посадки
  число ячеек не меняется.
- `overlap` — 9 icon-only схем; отдельно выбрана схема с 11 ячейками (index 6) и проверены ячейки 1/6/11.
- `calculate` для 14 пресетов: `equal_1/2/3/4`, `selected_r_5`, `equal_8/9`,
  `double_btb_10`, `equal_25`, `double_b_34`, `equal_36`,
  `selected_rb_overlap_2`, `double_b_overlap_5`, `selected_rlr_overlap_11` —
  ровно N слотов, позиции 1..N (1-based).
- 7 подвариантов 2×2 по-прежнему дают 4 ячейки; clear-all → PATCH all AUTO,
  detach → «Общая», canonical default не удалён.

## Ограничение
Ширина «11 icon-only вариантов» трактуется как 11-й диапазон `overlap` с
9 схемами; в бандле иного набора из 11 отдельных icon-схем нет.
