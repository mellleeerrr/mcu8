# ADR-0033. Пароли local_db — Argon2id (PBKDF2 только для миграции)

Статус: accepted (2026-10-29, T02)
Связано: ADR-0009 (аутентификация), BACKEND_RULES §1.3–1.4

## Контекст

`vks-auth::local_db` хранил пароли как PBKDF2-SHA256 (100 000 итераций) с
отдельной hex-солью. BACKEND_RULES §1.3 требует Argon2id, а живая БД содержит
две PBKDF2-записи (`user_credentials`), которые нельзя инвалидировать
одномоментно: иначе оператор потеряет вход при обновлении.

## Решение

1. **Новые и изменённые пароли** хешируются Argon2id с параметрами
   `m=19456 KiB, t=2, p=1` (OWASP-базлайн, ~19 MiB на хеш). PHC-строка
   (`$argon2id$v=19$m=19456,t=2,p=1$…`) хранится в существующей колонке
   `password_hash_hex`; `salt_hex` остаётся пустым — соль внутри PHC.
2. **PBKDF2-записи продолжают логиниться.** `verify_password` различает
   формат по префиксу `$argon2`: legacy-строка проверяется прежним
   PBKDF2-путём (100 000 итераций, constant-time сравнение).
3. **Ленивая миграция.** После успешного входа legacy-запись перехешируется в
   Argon2id в памяти и сохраняется в `user_credentials` best-effort. Поколение
   токена (`generation`) и метка `password_changed_at` **не меняются**:
   перехеширование — не смена пароля и не должно отзывать сессии.
4. **Ограничения нагрузки и длины.** Максимум 128 байт пароля (UTF-8) — и на
   входе, и при регистрации/смене. Одновременно выполняется не более 4 хешей
   (семафор), остальные ждут в ограниченной очереди (≤ 128 ожидающих); при её
   переполнении — `429` с `Retry-After: 1` (а не таймаут/500). Глобальный API-бюджет —
   token-bucket 200 burst / 50 токенов в секунду в `ApiV3State`.

## Последствия

- Живые PBKDF2-учётки входят без сброса пароля и сами становятся Argon2id.
- После миграции всех записей PBKDF2-путь можно удалить (отдельный таск).
- Хеширование стоит ~19 MiB памяти на запрос — важно для контейнеров с
  маленьким лимитом; параметры зафиксированы в `local_db.rs` и тестах.
- Колонка `salt_hex` остаётся в схеме ради legacy-строк; новые строки пишут
  пустое значение (обратная совместимость без миграции схемы).
