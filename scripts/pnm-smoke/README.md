# pnm-smoke — стаб-сервер и эмпирический контракт UI

Артефакты smoke-теста фронтенда PNM (перенесены из временного окружения итерации
импорта 2026-10-16, используются как справочник при реализации `api_v3`).

- `serve_pnm.py` — минимальный стаб-сервер: статика `/pnm/*` + `/mcu/*` из
  `client/pnm-frontend/deployed/pnm` (переопределяется `PNM_ROOT`) и минимальные
  заглушки `/api/v3/*`. Запуск: `python3 scripts/pnm-smoke/serve_pnm.py 8099`.
  Использовался, чтобы доказать: бандл без сборки рендерит экран логина и панель
  «Конференции» (скриншоты: `docs/progress/evidence/pnm-login-stub-2026-10-16.png`,
  `pnm-dashboard-stub-2026-10-16.png`).
- `observed_endpoints.json` — контракт API v3, снятый с живого UI (boot/login/shell/
  dashboard, WS, префиксы статики, мапперы форм).

Правила: стабы — только справочные; реальные формы ответов фиксируются тестами
`crates/vks-admin/src/api_v3/tests.rs` (фикстуры по этим данным + бандл).
